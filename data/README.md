# Data

This folder contains small datasets used throughout the computational training portfolio. The files support practice exercises and mini-projects in data manipulation, statistical analysis, Bayesian modeling, and behavioral research.

## File Structure

* 01-manual-mini-dataset-raw.txt — Manually created raw dataset used for introductory data-handling practice.
* 02-mini-project-congruent-raw.csv — Raw congruent-condition data used in the Stroop mini-project.
* 02-mini-project-incongruent-raw.csv — Raw incongruent-condition data used in the Stroop mini-project.
* 03-manual-mini-dataset-raw.csv — CSV version of the manually created practice dataset.
* 03-manual-mini-dataset-raw.xlsx — Excel version of the manually created practice dataset.
* 04-mini-project-raw.csv — Raw dataset used in an integrated data-analysis mini-project.
* 05-student-wellbeing-raw.csv — Raw student wellbeing dataset used for behavioral data-analysis practice.
* 06-stroop-simulated.csv — Simulated Stroop dataset used for Bayesian modeling practice.

## Notes

These files are primarily instructional datasets. They are used to demonstrate reproducible data-processing and analysis workflows rather than to serve as standalone research datasets.
