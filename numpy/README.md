# NumPy Practices for Behavioral and Experimental Data Analysis

## Overview

This folder contains a structured set of notebooks designed to teach and demonstrate professional use of NumPy for scientific data analysis. The focus is on vectorized computation, data manipulation, simulation, reproducibility, and numerical methods relevant to behavioral and experimental research.

## Folder Structure

* 01-ndarray-basics.ipynb — Introduction to `ndarray`, data types, shape, and memory considerations.
* 02-data-access-and-manipulation.ipynb — Indexing, slicing, fancy indexing, boolean masking, and views vs copies.
* 03-statistics.ipynb — Aggregations, axis logic, and statistical functions.
* 04-simulation-and-reproducibility.ipynb — Random number generation, simulation of experimental data, seeding, and reproducibility.
* 05-linear-algebra.ipynb — Dot products, matrix multiplication, solving linear systems, rank, and condition number.
* 06-performance-analysis.ipynb — Vectorization, memory layout, performance benchmarking, and optimization.
* 07-dataframe-basics.ipynb — Preparing arrays for downstream analysis in Pandas, including loading, cleaning, and reshaping.
* 08-mini-project-integration.ipynb — Full mini-project integrating simulation, data cleaning, statistical computation, and preparation for analysis pipelines.

## Key Skills Demonstrated

* Efficient array operations and vectorization
* Data simulation and reproducibility
* Data cleaning and preprocessing
* Basic numerical statistics and linear algebra
* Performance optimization
* Preparing data for research-ready pipelines
