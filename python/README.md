# Python Practices for Behavioral and Experimental Data Analysis

## Overview

This folder contains a structured set of notebooks designed to develop foundational Python programming skills for scientific and behavioral data analysis. The focus is on core programming concepts and practical coding patterns relevant to computational cognitive science and reproducible research.

## Folder Structure

* 01-basic-functions.ipynb — Introduction to defining, calling, and working with basic Python functions.

## Key Skills Demonstrated

* Python syntax and core programming concepts
* Function definition and usage
* Parameters and return values
* Writing reusable code
* Foundational programming practices for scientific computing
